# 英语岛大冒险：库洛米甜酷版

这是 [[英语岛大冒险_AI开发PRD]] 的可玩版本，采用 Sanrio Kuromi 视觉风格，共 200 个顺序解锁关卡，分布在 10 座主题岛：动物岛、校园岛、生活岛、美食岛、情感岛、自然岛、家庭岛、运动岛、身体岛、彩虹岛。原有前 8 关的本机进度会保留，完成动物岛后可直接进入第 9 关。视觉主题为库洛米甜酷风（粉色 + 深紫黑配色、骷髅徽章、蝴蝶结、jester hat 耳朵）。

新增课程覆盖入校问候、进教室、求助、认领物品、上厕所、交朋友、早餐、穿鞋、过马路、表达需要和情绪等场景。成语岛以中文彩蛋关呈现“一心一意、井井有条、助人为乐、画龙点睛”，避免与英语学习目标混在同一题中。

## 启动

在 Windows 文件资源管理器中双击 `启动游戏.cmd`。脚本会打开浏览器并在本机 `http://localhost:4173` 提供游戏。

也可以右键 `start.ps1`，选择“使用 PowerShell 运行”。

也可以在当前目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

关闭 PowerShell 窗口后，本地服务停止。游戏进度保存在浏览器本机，重新启动仍会保留。

直接双击 `index.html` 也能玩主要关卡，但离线安装、服务工作线程和部分浏览器语音功能需要通过本地地址运行。

## 华为 Pad 局域网使用

1. 让电脑和华为 Pad 连接同一个家庭路由器。
2. 第一次使用时，在电脑上双击 `启用平板访问.cmd`，在 Windows 提示中选择“是”。它只为专用网络开放 TCP 4173 端口。
3. 在电脑上双击 `启动游戏.cmd`，不要关闭弹出的 PowerShell 窗口。
4. 启动窗口会显示黄色的“华为 Pad 地址”，在平板浏览器中输入该地址。
5. 当前"从第 9 关继续"地址为 `http://192.168.1.28:4173/?v=15&resume=9`；局域网 IP 变化时，以启动窗口显示的地址为准。这个链接只会在平板没有进度时补齐前 8 关，不会覆盖已有平板进度。

局域网 HTTP 可以使用全部关卡和本地语音，但华为浏览器可能限制麦克风权限。遇到跟读关时可使用“我跟读了”完成。需要稳定的麦克风识别和桌面图标时，应部署到 HTTPS 网站后再添加到平板桌面。

## 今天的推荐玩法

- 第一次陪孩子完成第 1 关，让孩子知道“再听”按钮在哪里。
- 每次玩 1–2 关，约 8–15 分钟。
- 跟读示范可选择 `0.75× / 0.50× / 0.25×` 三档真实播放速度，默认 `0.75×`。麦克风挑战默认开启：第一次点击开始听，第二次点击“说完了”结束并判断。浏览器没有英语转写能力时，应用只检测是否持续开口并明确提示“不做发音评分”；家长仍可关闭麦克风并使用“我跟读了”。
- 家长区需要完成一道加法题；可查看已学单词、短语、成语、互动次数、正确率和时长设置。
- 主关卡和 Boss 口令使用随产品保存的自然语音 MP3，断网也能播放。英文由儿童音色 `en-US-AnaNeural` 预生成，中文成语由 `zh-CN-XiaoxiaoNeural` 预生成；浏览器/操作系统语音只在录音文件缺失时兜底。
- 家长区可分别试听“课程自然录音”和“系统兜底音色”。商用发布前应换成拥有明确商用授权的真人录音或正式 TTS 服务。

## 隐私

- 无账号、无广告、无外部分析服务。
- 进度仅保存在当前浏览器的 `localStorage`。
- 应用不保存录音或语音识别文本。
- 家长可在家长区一键清除全部本机数据。

## 验证

运行核心逻辑测试：

```powershell
node --test tests\game-core.test.js
```

核心内容/关卡结构测试需配合实际关卡数据：

```powershell
node --test tests\content.test.js
```

> 注：`tests/content.test.js` 此前基于早期 28 关 / 4 世界结构编写，当前代码已扩展到 200 关 / 10 世界。需要更新断言后才能稳定通过。`tests/game-core.test.js` 作为独立状态机测试始终通过。

浏览器端到端测试使用 Playwright：

```powershell
python tests/e2e.py              # 完整 E2E：隐藏答案、语音识别、移动端、离线、平板续关
python tests/echo-controls.e2e.py  # 跟读速度控制测试
python tests/visual-smoke.py     # 截图验收（桌面 + 移动端）
```

核心文件均为原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。
