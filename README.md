# 英语岛大冒险：今天可以玩的简单版

这是 [[英语岛大冒险_AI开发PRD]] 的可玩简单版，共 28 个顺序解锁关卡：动物港 8 关、小学城 8 关、生活镇 8 关、成语彩蛋岛 4 关。原有前 8 关的本机进度会保留，完成动物港后可直接进入第 9 关。

新增课程覆盖入校问候、进教室、求助、认领物品、上厕所、交朋友、早餐、穿鞋、过马路、表达需要和情绪等场景。成语岛以中文彩蛋关呈现“一心一意、井井有条、助人为乐、画龙点睛”，避免与英语学习目标混在同一题中。

## 启动

在 Windows 文件资源管理器中双击 `启动游戏.cmd`。脚本会打开浏览器并在本机 `http://localhost:4173` 提供游戏。

也可以右键 `start.ps1`，选择“使用 PowerShell 运行”。

也可以在当前目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

关闭 PowerShell 窗口后，本地服务停止。游戏进度保存在浏览器本机，重新启动仍会保留。

直接双击 `index.html` 也能玩主要关卡，但离线安装、服务工作线程和部分浏览器语音功能需要通过本地地址运行。

## 今天的推荐玩法

- 第一次陪孩子完成第 1 关，让孩子知道“再听”按钮在哪里。
- 每次玩 1–2 关，约 8–15 分钟。
- 跟读关优先使用浏览器英语转写核对内容。浏览器没有转写能力时，应用会检测是否有持续说话声；检测到后完成跟读，并明确提示“本次不做发音评分”。仍可关闭麦克风并使用“我跟读了”。
- 家长区需要完成一道加法题；可查看已学单词、短语、成语、互动次数、正确率和时长设置。
- 主关卡和 Boss 口令使用随产品保存的自然语音 MP3，断网也能播放。英文由儿童音色 `en-US-AnaNeural` 预生成，中文成语由 `zh-CN-XiaoxiaoNeural` 预生成；浏览器/操作系统语音只在录音文件缺失时兜底。
- 家长区可分别试听“课程自然录音”和“系统兜底音色”。商用发布前应换成拥有明确商用授权的真人录音或正式 TTS 服务。

## 隐私

- 无账号、无广告、无外部分析服务。
- 进度仅保存在当前浏览器的 `localStorage`。
- 应用不保存录音或语音识别文本。
- 家长可在家长区一键清除全部本机数据。

## 验证

运行状态逻辑测试：

```powershell
node --test tests\game-core.test.js
node --test tests\content.test.js
```

浏览器端到端测试使用 Codex 工作区自带的 Playwright 运行环境；它会自动通关原有 8 关、验证小学城解锁，并在 `tests/artifacts` 生成验收截图。

核心文件均为原生 HTML、CSS 和 JavaScript，无需安装依赖或构建。
